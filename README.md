# Spine Draft Kit

Генерує чернетки Spine 4.1.24 для слот-ігор: символи, барабани, рамки, фон, логотип, попапи. Чернетки мають фінальні назви, тому гра працює з ними одразу. Аніматор потім доробляє їх у Spine Editor і віддає файли з тими самими назвами.

## Що потрібно

- [Node.js](https://nodejs.org) 18 або новіший (перевірка: `node -v`). Більше нічого: кит не має залежностей, `npm install` не потрібен.
- Браузер Chrome, Safari, Firefox або Edge. Для превʼю й експорту потрібен інтернет: рантайм Spine і JSZip завантажуються з CDN.
- Spine Editor 4.1.24, щоб доробляти чернетки.

## Запуск

У папці кита:

```bash
npm run dev
```

Відкрий http://localhost:5180. Зупинити сервер: `Ctrl+C`. Інший порт: `PORT=5190 npm run dev`.

Файл `Spine-Draft-Kit.html` відкривається і без сервера, подвійним кліком. Але тоді проекти зберігаються тільки в браузері, а Connect не працює.

## Як працювати

1. **+ Новий** у сайдбарі: назва гри, сітка (барабани × ряди), розмір клітинки, кількість символів, компоненти.
2. У картках компонентів додай картинки. Назва PNG стає назвою символу: `high_1.png` → `animation_symbol_high_1`. Для кожної анімації задай тривалість і рух.
3. Справа «Сітка» показує барабани так, як їх покаже гра. **▶ Спін** запускає справжній спін. «Превʼю» відтворює кожен спайн.
4. **Експорт драфту** збирає zip. Інструкція для аніматора лежить у ньому, у `README.txt`.

Кнопка **i** біля кожного поля пояснює, що воно означає.

## Збереження проектів

Проекти автоматично зберігаються в двох місцях:

- у браузері (IndexedDB);
- у папці `projects/<назва>--<id>/`: `project.json` і картинки в `images/`. Це працює тільки через `npm run dev`.

Видалений проект переноситься в `projects/.trash/`. Якщо дані браузера зникнуть, кит відновить проекти з `projects/` під час запуску. Інша папка: `SPINE_KIT_DATA=/шлях npm run dev`.

Передати проект іншій людині: **Експорт** у сайдбарі створює один `.json` з картинками, а **Імпорт** його відкриває.

## Claude (MCP)

Claude Code може сам заповнити кит: просканувати папку з артом, створити проект або заповнити існуючий, додати символи й рамки, зробити скріншоти, запустити спін і зібрати zip. Усе відбувається наживо на відкритій сторінці.

1. Один раз додай сервер (шлях до своєї папки кита):

   ```bash
   claude mcp add --scope user spine-draft-kit -- node "/шлях/до/spine-draft-kit/mcp.mjs"
   ```

   Готову команду з правильним шляхом показує кнопка **Connect** у киті.
2. Запусти `npm run dev`, відкрий кит і натисни **Connect**. Колір крапки: жовта — кит чекає Claude, зелена — Claude підключений, синя — Claude працює.
3. У новій сесії Claude Code напиши, наприклад: «Заповни кит артом з `/Users/me/art/my-slot`». Claude спитає, заповнювати існуючий проект чи створити новий. Якщо кит не запущений, Claude запустить його сам.

Сервер кита приймає запити тільки з цього компʼютера. Прибрати MCP: `claude mcp remove spine-draft-kit -s user`.

## Для розробки кита

- `src/`: `core.js` (генератори, атлас, перевірка), `ui.js` (інтерфейс), `link.js` (Connect і копії на диск), `spin.js`, `store.js`, `info.js`, `page.html`.
- `npm run dev` стежить за `src/`, перезбирає і перезавантажує сторінку. `npm run build` збирає `dist/spine-draft-kit.html` і `Spine-Draft-Kit.html`.
- `server/bridge.mjs`: API проектів і міст до сторінки. `mcp.mjs`: MCP-сервер (stdio).
- `check/` містить шляхи до конкретного компʼютера і для передачі кита не потрібна.
